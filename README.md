# วันนี้ — Todo List

เว็บจัดการงานแบบมินิมอล ภาษาไทยทั้งหมด สร้างด้วย React + Vite + Tailwind CSS

## ติดตั้งและใช้งาน

ใช้ Node.js 20.19 ขึ้นไป หรือ 22.12 ขึ้นไป

```sh
npm install
npm run dev
```

เปิด URL ที่ Vite แสดงในเทอร์มินัล (โดยปกติ http://localhost:5173)

สร้างไฟล์สำหรับใช้งานจริงและดูตัวอย่าง:

```sh
npm run build
npm run preview
```

`npm install` จะสร้าง `package-lock.json` หลังติดตั้งสำเร็จ

## สถานะการตรวจสอบ

สภาพแวดล้อมที่สร้างโปรเจกต์ไม่สามารถเชื่อมต่อ registry.npmjs.org ได้ (ENOTFOUND) จึงยังไม่ได้ทดสอบ build หรือการทำงานในเบราว์เซอร์ ให้รันคำสั่งติดตั้งและ build ด้านบนในเครื่องที่เชื่อมต่อ npm ได้

## การใช้งาน

- พิมพ์งานและกด Enter หรือปุ่มลูกศรเพื่อเพิ่มงาน
- คลิกวงกลมเพื่อสลับสถานะเสร็จแล้ว
- ดับเบิลคลิกข้อความเพื่อแก้ไข หรือใช้ Tab เลือกข้อความแล้วกด Enter/F2
- ขณะแก้ไข กด Enter หรือคลิกนอกช่องเพื่อบันทึก กด Escape เพื่อยกเลิก ข้อความว่างจะเก็บงานเดิมไว้
- ปุ่มลบแสดงเมื่อชี้เมาส์หรือโฟกัสแถว บนอุปกรณ์สัมผัสแสดงตลอด
- กรองรายการและล้างงานที่เสร็จแล้วได้ด้านล่าง
- ปุ่มมุมขวาบนสลับโหมดสว่าง/มืด เริ่มต้นตามระบบและจำค่าที่เลือก

ข้อมูลและธีมบันทึกใน localStorage ของเบราว์เซอร์นี้โดยอัตโนมัติ ไม่ซิงก์ข้ามอุปกรณ์ หากเบราว์เซอร์ปิดกั้นพื้นที่จัดเก็บ แอปยังใช้งานได้ในหน้านั้นและแสดงข้อความแจ้งให้ทราบ

ใช้ Noto Sans Thai จาก Google Fonts โดยมีฟอนต์ sans-serif สำรองเมื่อออฟไลน์ รองรับ reduced motion และคีย์บอร์ด พร้อม focus ring และป้ายกำกับสำหรับโปรแกรมอ่านหน้าจอ
